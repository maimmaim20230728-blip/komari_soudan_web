# 困りごとから相談へ・そよぎ (Web版)

困りごとを言葉にして、相談先と、相談のときに確かめることがある名前を見る道具。診断はしません。端末内のみ・オフライン・登録なし・広告なし。

- 版: 0.9.2(Play版と同じ中身)
- 無料・広告なし・登録なし。答えや書いたことは保存せず、どこにも送りません(保存するのは設定だけ)
- 国: 日本(ja/en)・アメリカ(en)・フランス(fr/en)・ドイツ(de/en)・スペイン(es/en)・オランダ(nl)・韓国(ko)・台湾(zh)(国を選ぶと、ことばはその国のことばと、英語の中身がある国では英語)
- このフォルダは本体(非公開)から `node _sync_web.js` で作り直しています。ここを直接直さないでください
- 提供: 介護と支援の相談どころ「そよぎ」 https://soudansoyogi.com/
